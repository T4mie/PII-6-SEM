### Como rodar:
1. Para rodar o servidor, abra a pasta do projeto (BIM-Viewer) e rode o comando
´node backend.js´
Ele deve passar por todas as etapas do backend (Token, Criação do Bucket, Upload do arquivo, Tradução do arquivo)

2. Para rodar a aplicação, abra a pasta do projeto (BIM-Viewer) e rode o comando
´npm run dev´

### Observações:
- O arquivo que está no root do projeto e atualmente se chama ./racbasicsampleproject.rvt
- O client_id e o client_secret estão em um arquivo .env que a equipe do projeto possui
- Não se esqueça de fazer npm install após clonar o projeto
